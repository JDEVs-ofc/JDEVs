## 📖 Sobre o Site

Este é o site desenvolvido para apresentar o projeto **Parada de Ônibus Inteligente**, criado por alunos do 2º ano do Ensino Médio em 2023. O site foi construído do zero utilizando HTML, CSS e JavaScript puro, sem frameworks, como parte do trabalho da disciplina de Soluções Tecnológicas Inteligentes (STI).

## ✨ Funcionalidades

### 🏠 Página Principal
- Apresentação visual do projeto
- Navegação intuitiva
- Design responsivo e moderno

### 📄 Páginas do Site

| Página | Descrição | Arquivo |
|--------|-----------|---------|
| **Home** | Página inicial com introdução ao projeto | `index.html` |
| **Sobre** | Detalhes completos sobre o projeto e objetivos | `pags/sobre.html` |
| **Apoie** | Informações sobre como apoiar a iniciativa | `pags/ajude.html` |
| **Outros Projetos** | Links para redes sociais e projetos relacionados | `pags/redes.html` |
| **Agradecimentos** | Página de agradecimento | `pags/obg.html` |

### 🎨 Características de Design

- 🎯 **Menu de Navegação Responsivo** - Menu hambúrguer para dispositivos móveis
- 🎭 **Animações CSS** - Botão "Apoie" com animação de balanço
- 📱 **Design Responsivo** - Adaptável a diferentes tamanhos de tela
- ⚡ **Efeitos Hover** - Interações suaves nos elementos

## 💻 Como Executar Localmente

### Pré-requisitos
- Navegador web moderno (Chrome, Firefox, Edge, Safari)
- Editor de código (opcional)

### Passos

1. **Clone o repositório**
```bash
git clone https://github.com/JDEVs-ofc/JDEVs.git
cd JDEVs
```

2. **Abra o arquivo HTML**
```bash
# No Windows
start index.html

# No macOS
open index.html

# No Linux
xdg-open index.html
```

Ou simplesmente arraste o arquivo `index.html` para seu navegador.
